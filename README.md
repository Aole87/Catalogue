# Car Parts Catalog Desktop Application

ระบบแคตตาล็อกสำหรับแสดงสินค้าอะไหล่รถยนต์ขนาดเล็กและขนาดใหญ่ พร้อมระบบหน้าบ้านและหลังบ้าน

## วิธีการใช้งาน

1. **การติดตั้ง Dependencies**:
   เปิด Terminal ในโฟลเดอร์นี้แล้วรัน:
   ```bash
   npm install
   ```

2. **การรันแอปพลิเคชัน**:
   ```bash
   npm run electron:start
   ```

## ฟีเจอร์ของระบบ

### หน้าบ้าน (Frontend)
- **หน้าแรก**: แสดงแบนเนอร์, หมวดหมู่สินค้า, แบรนด์ และยี่ห้อรถ
- **ระบบสมาชิก**: สมัครสมาชิกและเข้าสู่ระบบ (แบ่งประเภทเป็น อู่, ร้านค้า, ลูกค้าทั่วไป)
- **หน้ารวมสินค้า**: ฟิลเตอร์ตามยี่ห้อรถ, หมวดหมู่ และแบรนด์
- **ราคาสินค้า**: แสดงราคาตามประเภทสมาชิกที่ล็อกอิน
- **หน้ารายละเอียดสินค้า**: แสดงข้อมูลทางเทคนิคและรูปภาพ

### หลังบ้าน (Admin Backend)
- **Dashboard**: สรุปสถิติสมาชิกและสินค้า
- **จัดการข้อมูล**: เพิ่ม/ลบ/แก้ไข หมวดหมู่, แบรนด์, และสินค้า
- **จัดการสมาชิก**: ตรวจสอบและจัดการสิทธิ์การเข้าใช้งาน
- **นำเข้าข้อมูล**: รองรับการ Import ข้อมูลจาก Excel (ผ่านระบบจัดการสินค้า)

## ข้อมูลเริ่มต้น (Seed Data)
- **Admin Login**: `admin` / `admin123`
- **Database**: SQLite (`database.sqlite`)
